# Каталог квартир: Минск и Минский район

Локальный каталог с Куфара, Реалта и Онлайнера: список и карта, фильтры, независимые оценки цены и удобства, избранное и уведомления в Telegram по сохранённым поискам.

Сбор не ограничен ценой, комнатностью или площадью. Доли, частные дома и Минск-Мир исключаются. Неоднозначные объекты, в том числе неподтверждённые карточки Онлайнера, находятся в разделе «Требующие проверки» и не участвуют в оценке рынка или рассылке.

## Запуск

Требуются Node.js 24+, pnpm 11 и Docker Desktop.

```powershell
pnpm install
if (!(Test-Path .env)) { Copy-Item .env.example .env }
docker compose up -d postgres otp
pnpm prisma:generate
pnpm prisma migrate deploy
pnpm dev
```

Разработка: http://127.0.0.1:5173. API: http://127.0.0.1:3000. PostgreSQL опубликована на порту 55432; OTP — на 8080. Перед запуском заполните Telegram-параметры в `.env`. Существующий `.env` заменять не нужно.

Для собранной версии:

```powershell
pnpm build
pnpm start
```

Каталог будет доступен на http://127.0.0.1:3000. Сервер доступен только с текущего компьютера. `CATALOG_PORT` изменяет порт API; Vite учитывает это значение.

## Переход Со Старой Версии

Миграции добавочные: удалять или очищать базу не требуется. При первом старте старые записи получают нормализованные характеристики и ставятся в очередь обогащения. Для повторного разбора сохранённого исходного JSON без запросов к площадкам:

```powershell
pnpm db:normalize-catalog
```

Первичный обход и загрузка подробностей идут в фоне и могут занять длительное время: запросы к каждой площадке выполняются последовательно, не чаще одного в секунду. Прогресс сохраняется в PostgreSQL. В разделе «Сбор» видны текущий статус, ошибки и количество обработанных записей. Частичный обход не означает отсутствие предложений.

## Оценки И Уведомления

- **Выгодность:** сравнение с минимум пятью близкими аналогами; нет общей медианы по всему Минску. При нехватке данных оценка отсутствует.
- **Удобство:** транспорт 35%, состояние квартиры и дома 35%, планировка 30%. Веса, точка назначения и крайнее время прибытия настраиваются.
- OTP рассчитывает реальный маршрут общественным транспортом и пеший путь до метро. Недоступность OTP не блокирует каталог.
- В подробной карточке видны формула выгодности, правила отбора аналогов и вклад критериев удобства. Карта показывает точку квартиры и участки маршрута до работы. Координаты работы задаются в «Настройки → Работа · точка назначения».
- Маршрут строится к заданному времени прибытия (по умолчанию 08:30). Основной вариант позволяет выйти как можно позже; при равном времени учитываются ходьба и пересадки. Отличающийся вариант с трамваем можно выбрать отдельно.
- В карточке можно указать личный бюджет в USD: отдельный расчёт сравнивает покупку вместе с ремонтом с готовыми квартирами. Сортировка и уведомления используют рыночный балл.
- Telegram включается отдельно для сохранённого поиска. Первая загрузка фиксирует исходную выборку без массовой рассылки; затем отправляются новые совпадения и снижение цены.

## Ремонт по фото

Установите [Ollama для Windows](https://docs.ollama.com/windows) или запустите переносимый `ollama serve` на `127.0.0.1:11434`. Загрузите локальную модель:

```powershell
ollama pull qwen3-vl:4b-instruct-q4_K_M
```

Задайте `PHOTO_REPAIR_ENABLED="true"` в `.env` и перезапустите каталог. Анализ выполняется только по кнопке в карточке; модель получает не более шести снимков, ни фото, ни описания не уходят в облако. Подтверждённая категория меняет выборку рыночных аналогов и критерий ремонта в удобстве. Поле продавца не перезаписывается. `pnpm test:photo-pilot` проверяет модель на небольшой выборке без записи результатов в БД.

## Проверки

```powershell
pnpm test
pnpm test:integration
pnpm test:browser
pnpm test:browser:detail
```

Интеграционные тесты требуют PostgreSQL и используют отдельную временную БД. Браузерная проверка требует запущенного каталога и установленного Chromium (`pnpm exec playwright install chromium`). Тесты не отправляют настоящие сообщения в Telegram.

Проверка карточки (`test:browser:detail`) дополнительно требует работающего OTP, доступных тайлов OpenStreetMap и хотя бы одной квартиры с пересчитанной оценкой.

GTFS и упаковка для OTP остаются отдельными командами:

```powershell
pnpm gtfs:scrape
pnpm gtfs:zip
```

Архитектура, критерии оценки, API и ограничения описаны в [docs/catalog.md](docs/catalog.md).
